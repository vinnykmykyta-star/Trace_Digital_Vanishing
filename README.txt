Як отримати TraceDigitalVanishing.exe (Windows)

1. Встановіть Node.js LTS: https://nodejs.org
2. Розпакуйте цю папку, двічі клацніть build_exe.bat
3. Через 1-3 хвилини з'явиться папка dist\TraceDigitalVanishing-win32-x64
4. Запускайте TraceDigitalVanishing.exe з цієї папки.
   Файли поруч з exe (dll, resources) видаляти не можна. Щоб передати гру, заархівуйте всю папку.

Перевірити гру без збірки: у цій папці виконайте npm install, потім npm start.
